# ImpactMap Desktop

Локальное приложение на Python и PySide6 для Windows и Linux. Для работы приложения нужны Git в `PATH` и Python 3.10 или новее с установленным PySide6. Приложение работает без сетевых запросов, ИИ и API-ключей.

## Установка и запуск

Выполните команды из корня ImpactMap.

**Fedora Linux**

```sh
sudo dnf install git python3-pyside6
cd desktop-py
python3 main.py
```

**Другие дистрибутивы Linux**

```sh
cd desktop-py
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

**Windows (PowerShell)**

```powershell
cd desktop-py
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Для установки без сети заранее подготовьте локальные колёса PySide6 и его зависимостей для вашей ОС и версии Python. Добавьте к команде установки `--no-index --find-links <папка-с-колёсами>`.

## Проверка изменений

1. Нажмите «Выбрать папку…» и выберите локальный Git-репозиторий с хотя бы одним коммитом. Если выбрана подпапка, приложение найдёт корень рабочей копии.
2. Нажмите «Проверить изменения». Слева появится список файлов, отличающихся от `HEAD` с учётом индекса и рабочей копии. В список также входят новые неигнорируемые файлы. При переименовании отображаются старый и новый пути.
3. Откройте карту зависимостей, список затронутых файлов или предупреждения. Стрелка `A → B` означает, что `A` использует `B`. Тип связи виден при наведении на стрелку.

Без доступного анализатора вкладки показывают содержимое [example.json](example.json). Строка состояния помечает пример, а слева остаётся список реальных изменений Git.

## Подключение Rust-анализатора

Передайте путь к готовому исполняемому файлу через `--analyzer` или переменную окружения `IMPACTMAP_ANALYZER`. Параметр командной строки имеет приоритет. Относительные пути к исполняемому файлу отсчитываются от каталога запуска. Имя команды также может разрешаться через `PATH`.

```sh
.venv/bin/python main.py --analyzer "/path/to/impactmap-analyzer"
```

```powershell
$env:IMPACTMAP_ANALYZER = 'C:\Tools\impactmap-analyzer.exe'
.\.venv\Scripts\python.exe main.py
```

Приложение передаёт запрос протокола версии 1 в UTF-8 через stdin и читает ответ из stdout. `repo_path` содержит абсолютный путь к корню рабочей копии, а `changed_files` содержит относительные пути с разделителем `/`. Ошибки Git и анализатора появляются во вкладке «Предупреждения».
