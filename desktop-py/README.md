# ImpactMap Desktop

[Установка и запуск на Windows и Fedora KDE](../README.md).

- **GitHub** открывается при запуске и проверяет `DarolCup/ImpactMap`. Чтобы выбрать другой публичный репозиторий, введите `владелец/репозиторий` или вставьте его HTTPS-ссылку и нажмите «Обновить с GitHub». ImpactMap сравнит последний коммит ветки по умолчанию с его первым родителем. Если обновление не удалось, в открытом окне остаётся предыдущий результат с пометкой об ошибке.
- **Локальная папка** проверяет изменения относительно `HEAD`. Выберите папку Git-репозитория и нажмите «Проверить изменения».

Сеть нужна для обновления с GitHub, анализ выполняется локально. Чтобы выбрать другой бинарник анализатора, передайте `--analyzer ПУТЬ` или задайте `IMPACTMAP_ANALYZER`. [Протокол и ограничения анализатора](../analyzer-rs/README.md).
